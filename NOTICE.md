# Source provenance

This project continues the Minecraft 1.7.10 backport at
https://github.com/mgomezch/SuperFactoryManager, based on TeamDman's
SuperFactoryManager. Existing source and resource license notices are retained.

The initial visual editor adapts graph and control-flow concepts from RetroSFM,
https://github.com/breakinblocks/RetroSFM, commit
`b6776c456e87ace2ada5e5464fea9e4367d74bad`.
Copyright (c) 2026 Saereth. The accompanying MIT notice is preserved at
`src/main/resources/META-INF/licenses/RetroSFM-MIT.txt` and bundled in the mod JAR.
The port uses the existing SFML/Java execution engine and Minecraft 1.7.10 APIs;
its layout encoding is not compatible with RetroSFM's modern JSON format.
