# Super Factory Manager

Move items between your machines with a small SFML program.

<BlockImage id="superfactorymanager:manager" scale="3" />

## Start here

**[Make your first transfer](/start/index.md)**

Build a tiny network, name two chests, and copy one short program.
You will move one item and keep the destination stocked at one.

## Already have a working route?

**[Advanced guide](/advanced/index.md)**

Find routing rules, variables, functions, queries and the complete Studio
workflow when you need them.

**[Nothing moving?](/start/troubleshooting.md)** Follow the short checklist.

## Copying a program

Use the copy button on an **SFML** code block, then paste into
**Manager > Program > Edit code**. Assign the example's labels before pressing
**Start**. Blocks marked **text** show fragments or terminal commands.

GuideNH search finds topics throughout this book. Hold your configured guide
key over an SFM item to open its page; the default is **G**.
